# 🛒 Aplikasi Penjualan Toko

Aplikasi Penjualan Toko merupakan aplikasi berbasis web yang dibuat menggunakan PHP Native dan MySQL untuk membantu mengelola kegiatan penjualan, mulai dari pengelolaan produk hingga laporan penjualan.

## ✨ Fitur Aplikasi

- Dashboard untuk melihat ringkasan data.
- Mengelola data produk.
- Mengelola kategori produk.
- Mengelola data pelanggan.
- Mengelola transaksi penjualan.
- Melihat riwayat transaksi.
- Membuat laporan penjualan.
- Melihat log aktivitas.
- Mengelola pembayaran.
- Mencetak label produk.

## 🛠️ Teknologi yang Digunakan

- PHP Native
- MySQL / MariaDB
- HTML
- CSS
- JavaScript
- Bootstrap 5
- XAMPP
